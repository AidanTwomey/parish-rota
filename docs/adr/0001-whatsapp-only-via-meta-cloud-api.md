# WhatsApp only, via Meta's Cloud API directly

Volunteers interact with the rota entirely by phone messaging, and running cost must be as close to zero as possible. We chose WhatsApp as the sole channel, integrated directly with Meta's Cloud API rather than through Twilio (whose per-message markup defeats the cost goal) and rather than SMS (~€0.05+/message both directions). Reader replies and 24-hour-window responses are free; only business-initiated template messages cost (~€0.03–0.05). The ~10% of readers without WhatsApp are handled manually by the Coordinator (phone call).
